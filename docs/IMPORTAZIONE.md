# Caricamento iniziale su GitHub

1. Estrarre lo ZIP sul computer.
2. Aprire il repository GitHub `cosa-manca`.
3. Premere **Add file** → **Upload files**.
4. Trascinare nella pagina tutti gli elementi estratti, non lo ZIP chiuso.
5. Nel messaggio del commit scrivere: `Importa Scorta Casa v1.2.0`.
6. Premere **Commit changes**.

Questo caricamento non modifica l'app già pubblicata su Cloudflare.
