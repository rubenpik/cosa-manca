# Scorta Casa

Repository ufficiale dell'app **Scorta Casa**.

## Versione iniziale importata

- Versione app: **v1.2.0**
- Stato: versione stabile attualmente pubblicata
- Frontend: PWA statica in HTML/CSS/JavaScript

## Struttura

- `app/` — applicazione PWA attuale
- `backend/` — futura API di sincronizzazione
- `database/` — futura struttura del database Cloudflare D1
- `docs/` — documentazione, decisioni e roadmap

## Regola di pubblicazione

La versione stabile non va sostituita direttamente con modifiche non testate. Le nuove funzioni verranno prima provate in una versione di test e pubblicate ufficialmente solo dopo approvazione.
